# RapChain

Alle Effekte für Rap-Vocals in einem VST3-Effekt-Plugin für FL Studio.

Signalweg: Input → Low Cut (24 dB) → EQ (Low / Mid / Air) → Kompressor → De-Esser → Sättigung → Delay (Ping-Pong) → Reverb → Output → Limiter

- Jedes Modul hat einen An/Aus-Punkt (rot = an).
- Doppelklick auf einen Regler setzt ihn zurück. Zahl anklicken = Wert eintippen.
- Oben Presets: Init, Rap Vocal – Clean, Trap Vocal – Dunkel & Fett, Hell & Airy, Ad-libs – Echo, Telefon / Lo-Fi.
- In FL: Mixer-Spur → leerer Slot → RapChain wählen (nicht im Channel Rack, ist ein Effekt).
